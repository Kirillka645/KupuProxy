# KupuProxy v1.4.0.4

Десктоп-клиент получил новый интерфейс в стиле Windows 11 (Fluent 2), прокси наконец
открываются прямо в Telegram, а не в браузере, и скан стал заметно быстрее — на ПК и на Android.

## ✈️ «Открыть в Telegram» — без браузера

Раньше при нажатии на прокси открывался браузер со страницей t.me: если схема `tg://` не была
зарегистрирована (portable-версия Telegram), клиент «падал» на t.me, а SOCKS5 вообще
передавался ссылкой `socks5://`, которую Telegram не понимает.

- Telegram Desktop ищется напрямую: обработчик `tg://` в реестре, уже запущенный процесс
  (Telegram, AyuGram, Kotatogram, 64Gram), типовые пути установки; на macOS — `Telegram.app`,
  на Linux — `telegram-desktop`, Flatpak, Snap и `~/.local/share/TelegramDesktop`.
- Прокси передаётся в Telegram так же, как это делает сам Telegram: `Telegram.exe -- tg://proxy?…`.
- SOCKS5 открывается ссылкой `tg://socks?server=…&port=…&user=…&pass=…`.
- **Браузер больше не открывается никогда.** Если Telegram не найден, ссылка копируется в буфер,
  а подсказка предлагает указать путь к Telegram.exe в настройках (для portable-версии).
- Новые кнопки: **«Скопировать прокси»** (ссылка t.me — удобно отправить другу),
  «tg://», «Скопировать адрес host:port», «Копировать все», «Экспорт…» в .txt.
- Двойной щелчок по строке, Enter или контекстное меню (правая кнопка) — открыть в Telegram;
  Ctrl+C — скопировать выбранный прокси.
- QR-код прокси в панели деталей: наведите камеру телефона — прокси откроется в Telegram.
- В меню трея: «Открыть лучший прокси в Telegram» и «Скопировать лучший прокси».

## 🎨 Новый дизайн ПК-клиента (Fluent 2)

- Панель навигации как в «Параметрах» Windows 11: Главная, Прокси, Источники, Настройки;
  сворачивается до иконок, на «Прокси» — счётчик найденного.
- Фон Mica, «слой контента», карточки с тонкой обводкой, типографика Fluent
  (Caption / Body / Subtitle / Title), акцентный цвет **берётся из Windows** — либо бирюзовый
  KupuProxy или синий Fluent на выбор.
- Свои Fluent-контролы: кнопки (акцентная / стандартная / subtle), ToggleSwitch «Вкл./Откл.»,
  TextBox с акцентной линией, ComboBox, Slider, тонкая полоса прогресса, InfoBar-уведомления,
  подсказки, тонкие полосы прокрутки, тёмное контекстное меню в тёмной теме.
- «Прокси» — таблица с колонками (статус, адрес, протокол, задержка, jitter, источник),
  сортировка по клику на заголовок, фильтры-переключатели протоколов с количеством,
  «Только избранные», поиск, порог задержки и панель деталей.
- «Главная» — карточка скана с прогрессом, метрики, лучшие прокси с быстрыми действиями,
  гистограмма задержек и график трафика с заливкой.
- «Настройки» — карточки в стиле Windows 11, сгруппированные по разделам.
- Минимальный размер окна, чтобы раскладка не ломалась.

## ⚡ Быстрее скан

- **Не повторяется TCP-префлайт.** Фаза рукопожатия заново проверяла TCP-доступность каждой
  записи (до 0,9 с и лишнее соединение на прокси), хотя фаза 1 только что это сделала.
  Исправлено и на ПК, и на Android.
- Префлайт идёт в 3 раза большим числом потоков (по умолчанию 192 на ПК, на Android — вдвое
  больше, чем потоков рукопожатия), таймаут префлайта — 700 мс.
- Рабочие прокси появляются сразу после первого замера: дополнительные замеры для jitter
  делаются отдельной фазой «Замер стабильности» только по найденным прокси, а не по всем.
- В настройках: число потоков (16–256) и таймаут соединения (0,5–3 с).

## ➕ Ещё на ПК

- Результаты последнего скана сохраняются и показываются после перезапуска (с пометкой и
  кнопкой «Перепроверить»).
- «Перепроверить» — быстро освежить уже найденный список.
- Источник «Из буфера обмена»: скопируйте ссылки или список host:port — клиент их разберёт.
- Проверка обновлений по `update_manifest.json` (GitHub → jsDelivr) и InfoBar «Доступна версия».
- Уведомление в трее о завершении скана, если окно свёрнуто.
- Опция «Сканировать при запуске», «Избранные — первыми», кнопка «Открыть папку данных».
- Горячие клавиши: Ctrl+R / F5 — скан, Ctrl+F — поиск, Enter — открыть, Ctrl+C — копировать,
  ↑/↓ — выбор, Ctrl+1…4 — разделы, Esc — остановить скан.
- В строке прокси видно, из какого источника он пришёл, и время проверки.

## 📦 Сборка

```bash
./gradlew assembleRelease                         # APK
./gradlew :desktop:packageUberJarForCurrentOS     # запускаемый jar
./gradlew :desktop:packageMsi                     # Windows .msi
./gradlew :desktop:packageDeb                     # Linux .deb
./gradlew :desktop:packageDmg                     # macOS .dmg
```

## 🔄 Обновление

APK обновляется обычным автообновлением. Десктоп-клиент — отдельная загрузка; начиная с этой
версии он сам сообщает о новых релизах. Установщики используют версию пакета 1.4.4.

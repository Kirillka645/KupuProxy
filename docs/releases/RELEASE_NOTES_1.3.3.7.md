# KupuProxy v1.3.3.7

## Изменения
- Добавлена карточка **Dubblebyte free MTProto** на главный экран (под Kort Verified Collector). Нажатие открывает репозиторий: [github.com/dubblebyte/free-mtproto-proxies](https://github.com/dubblebyte/free-mtproto-proxies).
- Улучшен subtitle источника Dubblebyte в разделе «Быстрый старт».

## Как использовать
Нажмите на карточку Dubblebyte на главном экране — откроется GitHub-репозиторий источника.
Также доступен в разделе «Быстрый старт» как отдельный источник прокси.

# KupuProxy v1.3.3.3

Большое обновление скорости, безопасности и интерфейса.

## Что нового

- Полный переход основных экранов на Jetpack Compose и Material 3.
- Новый главный экран, live-скан, список результатов, проверка файла и экспорт общего списка.
- Ускоренный мультиформатный парсер с лимитами входа/результатов и предкомпилированными шаблонами.
- Ограниченный пул MTProto-воркеров вместо одной корутины на каждый адрес.
- Надёжная ранняя остановка после достижения цели и корректная отмена сканирования.
- Ускорен FakeTLS-буфер: удалена квадратичная обработка через `removeAt(0)`.
- Единый путь загрузки источников через `ProxySourceRegistry` и `ProxyAggregator`.
- Безопасные пользовательские HTTPS-источники: блокировка localhost, LAN, reserved IP, опасных redirect и DNS rebinding.
- Ограничение размера сетевых ответов, manifest, импортируемых источников и файлов прокси.
- Экспорт в Downloads через MediaStore на Android 10+.
- Усиленный встроенный updater: проверка URL/asset, размера, SHA-256, package name, версии и сертификата подписи.
- Резервное копирование данных приложения отключено.
- Добавлен GitHub Actions CI: unit tests, lint и debug APK.

## Совместимость обновления

APK v1.3.3.3 подписан тем же сертификатом, что и v1.3.3.2, поэтому устанавливается поверх предыдущей версии без удаления приложения.

## Проверки релиза

- Unit tests
- Android lint
- Debug/release assembly
- SHA-256 checksum
- APK package/version/signature verification

# KupuProxy v1.3.3.5

Патч выпускается отдельно от большой локализации: языки и остальные незавершённые улучшения перейдут в v1.3.3.6.

## Исправлено

- Восстановлено обновление APK для пользователей v1.3.3.3 и v1.3.3.4.
- Добавлена надёжная загрузка метаданных через GitHub latest/recent releases и резервный `update_manifest.json`.
- Добавлена ручная проверка обновлений в настройках.
- Добавлены видимые состояния проверки, сообщения об ошибках и повтор.
- После выдачи разрешения «Установка неизвестных приложений» используется уже скачанный и проверенный APK без повторной загрузки.
- Проверка обновления подтверждает официальный GitHub Release, SHA-256, размер, package name, версию и совместимый сертификат подписи.
- Yagami200 Free полностью удалён из Android-приложения, manifest, exteraGram-плагина и документации.

## Совместимость обновления

APK подписан тем же сертификатом, что v1.3.3.3 и v1.3.3.4:

`947e17a19736ed4d9fac3f100ce5b8a04102651366713642d08b7cd08f7b237f`

Это позволяет Android установить v1.3.3.5 поверх предыдущих версий без удаления приложения.

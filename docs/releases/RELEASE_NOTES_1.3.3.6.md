# KupuProxy v1.3.3.6

## Новое
- **Выбор языка приложения**: 20 языков (русский, английский, украинский, немецкий, французский, испанский, итальянский, португальский (Бразилия), польский, турецкий, арабский, персидский, хинди, индонезийский, японский, корейский, китайский (упрощённый/традиционный), вьетнамский, казахский) + Follow system.
- **Удаление Yagami200**: миграция автоматически очищает кэш при первом запуске.
- **Укрепление Dubblebyte**: mirror-first с upstream fallback.
- **Полный аудит приложения**: локализация NetworkProfile, исправление KSP-бага, чистка `values-en`, тесты ресурсов.

## Как выбрать язык
Настройки → Язык приложения → выберите язык или «Как в системе».

## Совместимость обновления
APK подписан тем же сертификатом (SHA-256 `947e17a19736ed4d9fac3f100ce5b8a04102651366713642d08b7cd08f7b237f`). Установка поверх v1.3.3.3–1.3.3.5 без удаления приложения.

# План следующих изменений

Этот PR закрывает первый этап: исправления релизов/упаковки, явная Android-подпись,
проверка сертификата и обязательных артефактов, ASCII-метаданные MSI (WiX LGHT0311), единые версии, иконки, регрессионные тесты,
Dependabot и базовая документация. Он не объявляет архитектурный рефакторинг завершённым.

## Перед следующим релизом

- [ ] Дождаться зелёной полной matrix-сборки на GitHub Actions.
- [ ] Настроить secrets и fingerprint исходного сертификата по `releases/SIGNING.md`.
- [ ] Проверить обновление с установленного официального APK на физическом устройстве.
- [ ] Проверить запуск и установку всех Desktop-пакетов на целевых ОС, включая обновление MSI.

- [ ] Подготовить новую версию и release notes; не перепубликовывать старый тег.

## Этап 4 — надёжность (около недели)

- [ ] Отмена скана, лимиты соединений, отсутствие coroutine/socket leaks.

Не привязывать завершение рефакторинга к размеру файла или произвольному проценту покрытия:
критерий — сохранённое поведение, измерения и воспроизводимые тесты.

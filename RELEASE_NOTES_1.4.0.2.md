# KupuProxy v1.4.0.2

Первый релиз с десктопным клиентом и с поддержкой не только MTProto.

## 🖥 Десктоп-клиент (Windows / Linux / macOS)

Новое приложение на Compose Multiplatform. Логика проверки прокси не переписывалась: она
живёт в общем модуле `:shared`, который собирается и под Android, и под десктоп, поэтому
мобильная и десктопная версии не могут разойтись по поведению.

**Стек выбирался под проект, а не под вкус.** Варианты Tauri, Electron и PyQt6 отпали:
они потребовали бы переписать весь парсер, проверку MTProto и логику источников на другом
языке и в другой экосистеме. Compose Multiplatform переиспользует тот же Kotlin и тот же
Compose, который уже используется в приложении.

Что умеет:

- **Обзор** — метрики, график трафика за сессию и распределение задержек по корзинам;
- **Прокси** — поиск по хосту и ссылке, фильтр по задержке и по протоколу, избранное,
  сортировка по задержке и jitter;
- **Источники** — локальный файл или URL со списком; поддерживаются те же форматы, что и
  на Android: txt, `host:port:secret`, JSON, YAML, markdown-таблицы, HTML и base64;
- **Маршрутизация** — встроенный локальный HTTP CONNECT-прокси на случайном порту
  127.0.0.1, который перенаправляет трафик через выбранный прокси и считает трафик;
- **Системный трей** — сворачивание в трей вместо закрытия, запуск из трея, выход;
- **Автозапуск** при входе в систему: реестр на Windows, LaunchAgent на macOS,
  XDG autostart на Linux. Системный механизм, а не копирование бинарника в автозагрузку, —
  иначе клиент запускался бы из устаревшей копии;
- **Тема** — системная, светлая или тёмная.

Клиент умеет открываться сразу на нужном разделе: `KupuProxy --tab=proxies`.

## 🔌 Поддержка SOCKS5, HTTP и WEB-прокси

Раньше парсер понимал только MTProto. Любая SOCKS-ссылка молча отбрасывалась — без проверки
и без записи в историю, — а HTTP и WEB-прокси не поддерживались вовсе.

Теперь протокол определяется явно, хранится в записи прокси и учитывается при дедупликации:

| Протокол  | Ссылка                                    | Как проверяется                       |
|-----------|-------------------------------------------|---------------------------------------|
| MTProto   | `tg://proxy?server=…&port=…&secret=…`      | рукопожатие MTProto, ответ `resPQ`    |
| SOCKS5    | `socks5://user:pass@host:port`, `tg://socks?…` | RFC 1928 / RFC 1929 + `CONNECT`   |
| HTTP      | `http://user:pass@host:port`               | `CONNECT` с `Proxy-Authorization`     |
| WEB       | `https://user:pass@host:port`              | то же поверх TLS                      |

Учитываются логины и пароли, IPv6 в квадратных скобках и `@` внутри пароля. Приватные
и зарезервированные адреса (`127.0.0.0/8`, `10/8`, `192.168/16`, `fc00::/7` и прочие)
отбрасываются на этапе разбора.

## ⏱ Задержка, jitter и стабильность соединения

Раньше измерялся один замер, jitter не считался вовсе, а список сортировался только по
задержке. Теперь:

- по умолчанию на прокси выполняется несколько замеров подряд;
- показываются средняя задержка, разброс (jitter) и число замеров;
- сортировка — по задержке, затем по jitter: нестабильные прокси уходят вниз списка;
- появился индикатор качества соединения: точка с плавной сменой цвета вместо
  безликой «галочки».

## ⚡ Двухэтапная проверка

Сканирование разбито на два этапа. Сначала один короткий TCP-запрос на каждый уникальный
`host:port`, и только потом полное рукопожатие протокола для тех, кто принял соединение.

**Зачем.** Крупные коллекторы отдают несколько разных секретов на один и тот же мёртвый
адрес. Раньше на каждый такой адрес тратилось полное криптографическое рукопожатие с
таймаутом. Теперь мёртвые адреса отсекаются одним дешёвым запросом.

## 🎨 Оформление: палитра и анимации

**Главное — палитра была рассинхронизирована.** Иконка приложения и тема окна рисовались
в `#00C2A8` на `#0B1220`, а Compose-схема оставалась на `#006C61` из Material Theme Builder.
В итоге стартовый экран не совпадал с иконкой. Теперь фирменные значения из иконки —
единый источник правды для обеих платформ, остальные палитры в настройках сохранены.

Другое:

- отступы, радиусы и размеры иконок вынесены в общие токены вместо разброса
  12/14/16/18/20 dp, который накопился за прошлые версии;
- добавлены анимации: появление результатов скана, переключение избранного, открытие
  панелей фильтров. Раньше переходы были мгновенными;
- карточки списка получили явную рамку в 1 dp — раньше её не было ни в одном экране,
  хотя она была описана в теме;
- в списке появился поиск и фильтр по протоколу.

## 🐛 Исправления в разборе конфигураций

Найдены тестами и исправлены две ошибки, из-за которых часть форматов не разбиралась
никогда:

- **YAML не работал вообще.** Проверка наличия `type:` в документе использовала регулярное
  выражение с `^…$` без флага MULTILINE, поэтому совпадение искалось только во всём тексте
  целиком и всегда возвращало `false`. Любой YAML-список молча игнорировался;
- **терялись логин и пароль.** Блок YAML закрывался, как только появлялись `host` и `port`,
  но `username`/`password` в таких файлах идут после них. Запись собиралась без учётных
  данных и не проходила проверку. Теперь блок накапливается целиком и закрывается на
  границе записи.

Обе ошибки воспроизводятся на тестах в `shared`.

## 📦 Сборка

Подробные команды — в [README](README.md#сборка). Коротко:

```bash
# APK
./gradlew assembleRelease

# Desktop
./gradlew :desktop:packageUberJarForCurrentOS        # запускаемый jar
./gradlew :desktop:packageMsi                        # Windows .msi
./gradlew :desktop:packageDeb                        # Linux .deb
./gradlew :desktop:packageDmg                        # macOS .dmg
```
